### About me

- 🪪 I build **digital identity** software for Android: Aadhaar flows, ISO/IEC 18013-5 mobile documents, OpenID4VP presentation, NFC and BLE.
- 🦀 I write security-critical code in **Rust** and **Kotlin**, and backend services in **Go**.
- ☁️ I contribute to **Meshery**, a CNCF cloud native manager.
- 🤝 Open to collaborating on identity, mobile security and cloud native open source.
